METHODOLOGY
----------------------------------------------------------------------
The model recursively predicts future network states.
Each predicted state becomes part of the next input sequence.

Predictions are grouped by the actual label of the target state.
The persistence baseline repeats the last observed state.

Only forecasts with consecutive one-second timestamps
inside the same temporal segment are evaluated.
